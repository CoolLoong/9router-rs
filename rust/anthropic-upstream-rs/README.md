## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the napi-rs module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## JSON and sequence replay

The fixtures freeze the clock and capture the original non-streaming Anthropic
conversion and the original SSE translator. The adapter compiles the same
anthropic_upstream.rs used by the application. It records per-frame output and
the final accumulated usage, including raw cache counters.

~~~sh
rust-anything record rust/anthropic-upstream-rs \
  --module "$PWD/rust/anthropic-upstream-rs/reference.mjs" \
  --inputs rust/anthropic-upstream-rs/inputs.jsonl
rust-anything gate rust/anthropic-upstream-rs
~~~
