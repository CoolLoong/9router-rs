9Router native preview

Run ./9router --version or .\9router.exe --version to check the release version.
On Linux and macOS, run ./9router --host 127.0.0.1 --port 20128 --no-browser.
On Windows, run .\9router.exe --host 127.0.0.1 --port 20128 --no-browser.
Visit http://127.0.0.1:20128/dashboard or check http://127.0.0.1:20128/api/health.

The package runs the migrated gateway, dashboard and CLI without Node.js.
Routes still awaiting migration report HTTP 503 with “Legacy runtime unavailable for this route”.
This archive is an unsigned preview for the target listed in manifest.json.
