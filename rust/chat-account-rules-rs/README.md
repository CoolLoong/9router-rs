## Loop

```sh
rust-anything record . --inputs "$PWD/inputs.jsonl"
rust-anything build .    # build the napi-rs module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

`accounts-http.jsonl` records the stateful API behavior with the local mock
upstream. Use the repository's `rust/reference/server.sh` with
`NINEROUTER_MIGRATION_FIXTURE=1` in an isolated network namespace. The recording
covers account-scoped rate limiting, request-scoped 400 errors and sticky
round-robin order.
