```sh
rust-anything build .    # build the napi-rs module
rust-anything diff .     # run the recorded cases against Rust

```

## SQLite resolver replay

The replay harness executes the upstream resolver and repositories against synthetic in-memory SQLite. The Rust program invokes the exact gateway resolver source against the same fixture. From the repository root:

```sh
replay=rust/gateway-model-resolver-rs/db-replay
cargo build --manifest-path "$replay/Cargo.toml"
unshare -Urn -- rust-anything app record "$replay" --inputs "$replay/inputs.jsonl" --no-traps -- node --no-warnings original.mjs
unshare -Urn -- rust-anything app replay "$replay" --build target/debug/model-resolution-replay
```
