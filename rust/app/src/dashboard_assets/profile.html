AWS IAM Identity Center
Add a custom SAML 2.0 application. Fill in the application ACS URL and SAML audience. Map the Subject or email attribute to ${user:email}, then import the application's metadata XML.
Microsoft Entra ID
Create an enterprise application with SAML single sign-on. Set Identifier to the entity ID and Reply URL to the ACS URL. Import the federation metadata XML or upload the IdP certificate.
Okta / Auth0
Create a SAML 2.0 integration. Set the single sign-on URL to the ACS URL, the Audience URI to the entity ID and the NameID format to EmailAddress. Import the IdP metadata or upload the certificate.
Keycloak / Authentik
Create a SAML client. Use the entity ID as the client ID and the ACS URL as the SAML processing URL. Import the exported SAML descriptor or upload the IdP certificate.
