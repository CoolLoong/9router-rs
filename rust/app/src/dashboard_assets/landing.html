Get started

  1. Start 9Router.
  2. Add your providers and credentials in the dashboard.
  3. Set your tool’s base URL to the gateway endpoint shown in the dashboard.
Open dashboard

Start 9Router from the upstream npm package.

npx 9router

Default dashboard
http://localhost:20128/dashboard

Data file on Windows

How 9Router works

  1. Send a request

    Your CLI or SDK uses the gateway URL and a model ID.

  2. Select a route

    9Router applies the model, account, and combo rules you configure.

  3. Receive the result

    The selected provider handles the request. 9Router returns the response to your client.
