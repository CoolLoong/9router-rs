## Sequence replay

The replay adapter accepts a sequence of OpenAI Chat chunks, with optional
initial usage. It records the upstream translator's events after each chunk and
after EOF, then runs those inputs through the same Rust state machine used by
the application.

~~~sh
rust-anything record rust/claude-sse-rs \
  --module "$PWD/rust/claude-sse-rs/reference.mjs" \
  --inputs rust/claude-sse-rs/inputs.jsonl
rust-anything gate rust/claude-sse-rs
~~~

The HTTP stream adapter handles SSE framing, usage padding and estimates. This
unit handles translation and the raw Anthropic usage projection. It emits a
terminal pair once, on the first upstream finish reason, and emits nothing at
EOF.
