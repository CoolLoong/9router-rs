# 当前配置的原版对照

原版为迁移源提交 `1855aa44`，用 Node.js 22.23.5 从源码构建 `0.5.119` CLI，然后经 `custom-server.js` 启动。Rust 对照包含本机 paru 安装版 `e21d4d6b` 和工作区修复版。原版用 `rust-anything` 自回放 36/36 组通过，基线无通配符。

| 对照版本 | 整组完全一致 | 单步完全一致 | HTTP 响应一致 |
| --- | ---: | ---: | ---: |
| 本机 paru 版 | 19 / 36 | 136 / 182 | 152 / 181 |
| 工作区修复版 | 21 / 36 | 146 / 182 | 166 / 181 |

单步比较包含 HTTP 响应、模拟上游调用次数和出站请求。181 步为 HTTP，另一步为 `9router show claude codex --json`。列表和错误响应都纳入严格比较。

## 通过的行为

- 登录、登出、远程 API key 校验、兼容节点本地验证与远程限制。
- Provider 连接、兼容节点、组合、网关密钥、自定义模型的管理操作，以及模型显隐和设置写入。
- Gemini 原生 `generateContent` 与流式入口。兼容 Chat Completions 节点通过当前五个历史 API 入口的流式与非流式测试。
- Claudebox 的推理字段、工具记录和工具调用获得与原版一致的客户端响应。paru 版的 14 个 Codex 400 在工作区修复版全部消失。
- 两版共同支持的 `cx/gpt-6.1-sol` 在五个历史入口上的流式与非流式请求全部匹配。通用 Responses 请求使用 Provider 的 `max`，原生 Codex 客户端保留请求的 `high`，模型后缀可选择 `xhigh`。

## 剩余差异

| 范围 | 原版与工作区的差异 |
| --- | --- |
| GPT‑6.2 模型及出站协议 | 原版模型目录缺少这组本地模型映射。Rust 为部分 6.2 请求使用 Codex Lite 的工具与指令前缀。对应客户端响应已对上，出站字段仍不同。 |
| 模型目录 | 可见条目、上下文上限和部分能力字段不同。严格回放保留这些差异。 |
| Gemini 非流式跨协议 | 原版在 Claude Messages 和 OpenAI Responses 路径返回 Chat Completions 格式，Rust 按入口返回对应协议。 |
| Dashboard | `/dashboard/models` 和 `/dashboard/updates` 在原版返回 404，在 Rust 返回 200。 |
| 用量聚合 | 原版把原始网关 API key 拼进聚合对象键，Rust 使用哈希键。 |
| 免费模型 | 原版在模拟上游下可转发 OpenCode 免费模型，Rust 返回 403 并要求官方客户端。MiMo 免费模型在隔离环境中原版返回网络 502，Rust 返回已退役的 410。 |

严格验收没有全绿。对齐剩余差异会涉及 GPT‑6.2 映射、已有页面、响应协议和密钥处理的取舍。真实供应商认证和推理、浏览器交互、托盘及升级安装另行验证。当前运行服务仍是 paru 安装版。
